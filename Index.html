個人服務 icon

快速加入(圖示已對應好)：

桌布設定

請貼「圖片本身」的網址（通常以 .jpg / .png / .webp 結尾），不是打開圖片的網頁連結。在圖片搜尋結果上對圖片按右鍵選「複製圖片位址」，貼過來的才是正確網址；貼錯會顯示不出來。建議挑寬螢幕比例（16:9）的圖，套用起來比較不會被裁切怪異。貼多行（一行一個網址）會自動輪播，每 5 分鐘換一張。（Google 雲端硬碟的分享連結目前無法直接使用。）

更換圖示

請貼「圖片本身」的網址（通常以 .jpg / .png / .webp 結尾），不是打開圖片的網頁連結——對圖片按右鍵選「複製圖片位址」才會拿到正確網址。建議挑接近正方形、背景乾淨或透明的圖，縮成小圖示時比較清楚。

背景音樂設定

請貼「音檔本身」的直接網址（通常以 .mp3 / .ogg / .wav 結尾），不是網頁連結。瀏覽器會擋自動播放有聲音的內容，所以套用後要自己按桌面上的「▶️ 音樂」才會開始播放。貼多行（一行一個網址）會變成播放清單，一首放完接下一首，循環播放。（Google 雲端硬碟的分享連結目前無法直接使用；YouTube 連結也還不支援。）

雲端硬碟音樂播放器

列出目前這個資料夾裡的音檔。點一首會在一個小視窗裡用 Drive 自己的播放器打開——放完要手動點下一首，不會自動接歌（跨視窗沒辦法互相通知）。這個小視窗可以用 Chrome 的分割視窗功能跟桌面並排。
